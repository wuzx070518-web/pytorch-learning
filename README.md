## 本仓库代码

- `tensor/tensor_create.py`：Tensor 创建与 NumPy 转换练习。
- `tensor/tensor_stack.py`：Tensor 索引、拼接和原地操作练习。
- `autograd/train.py`：自动微分相关练习；使用预训练 ResNet18，首次运行可能下载模型权重。
- `convolutional neural network.py`：搭建卷积层、池化层、展平层和全连接层，练习前向传播、MSE 损失、反向传播及一次参数更新。
- `classifier.py`：基于 CIFAR-10 练习卷积网络分类、交叉熵损失和带动量的 SGD；首次运行训练并保存权重，之后读取已有权重进行分类评估。

以上代码主要用于学习和验证概念，不代表已完成系统的模型调参或对照实验。`classifier.py` 会下载 CIFAR-10 数据，数据目录和训练权重文件不会提交到仓库。详细任务完成情况与反思见科研周报。
